# ZJY270S0700XG31

中景园（ZJY）系 2.7" OLED。ユーザー確認済み: **256×64 / 7 pin**。

## 確定スペック

| 項目 | 値 |
|------|-----|
| 型番 | ZJY270S0700XG31 |
| サイズ | 2.7" |
| 解像度 | **256 × 64** |
| コントローラ | SSD1322 |
| 灰階 | 16 階調 |
| コネクタ | **7 pin**、4-wire SPI |
| ロジック / 電源 | 3.3 V |

U8g2: `U8G2_SSD1322_NHD_256X64_1_4W_SW_SPI`（ページバッファ・ソフト SPI）

## 配線（確定）

| 表記 | Nano | 役割 |
|------|------|------|
| GND | GND | グランド |
| VCC | **3.3 V** | 電源 |
| CS | **D9** | チップセレクト |
| RES / RST | **D6** | リセット |
| SCL / CLK / D0 | **D5** | SPI クロック |
| DC / A0 | **D4** | データ／コマンド |
| SDA / DIN / D1 | **D3** | SPI データ |

D13/D11 のハードウェア SPI は使わない（ソフト SPI）。

## レベルシフト

Nano 5 V → OLED 3.3 V。対象: **D9, D6, D5, D4, D3**（片方向で可）。
