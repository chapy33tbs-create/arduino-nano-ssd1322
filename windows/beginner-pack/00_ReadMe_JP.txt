================================================
  Oil / Water Gauge — 書き込み（お客様PC向け）
================================================

XLoader / Arduino IDE は使いません。
Edge または Chrome だけで書き込みます。

1. このフォルダを「ドキュメント」などに置く
2. HOWTO_PowerShell_Paste.txt を開く
3. Windows PowerShell を開き、書いてあるブロックを貼り付け
4. ページで「書き込む（Old Bootloader）」
   失敗時は「New Bootloader」

書き込み中は PowerShell 窓を閉じないこと。
油温・水温: 2秒更新 / 油圧: 0.5秒更新
A0=油温 / A1=油圧 / A2=水温
